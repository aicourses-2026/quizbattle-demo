QuizBattle — викторина «Насколько хорошо ты меня знаешь?»
Браузерная игра-викторина в стиле Kahoot. Работает на телефоне и компьютере. Опубликована на GitHub Pages: каждое изменение после commit + push видно по живой ссылке.
Стек и структура
Чистый HTML + CSS + JavaScript, без фреймворков (никакого React/Vue).
index.html — разметка, style.css — стили, script.js — логика игры.
questions.js — список вопросов и ответов.
Проверка: открыть index.html в браузере и пройти викторину до конца.
Правила работы
Меняй по одному изменению за раз. Не делай несколько несвязанных правок сразу.
Не трогай questions.js без явной просьбы.
Не переименовывай и не удаляй файлы.
Сохраняй крупные цветные кнопки и стиль Kahoot.
После изменения коротко скажи, какие файлы затронул.
Не говори «работает», если не проверил. Если проверить не можешь — так и скажи.
Не делай git push без моей команды.
Стиль кода
Комментарии — на русском, имена переменных — на английском.
Никаких внешних библиотек без моего разрешения.
