# QuizBattle 🎯

Викторина «Насколько хорошо ты меня знаешь?» в стиле Kahoot: 5 вопросов, 15 секунд на ответ, бонус за скорость.

**Играть:** https://ЛОГИН.github.io/quizbattle/

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы: экраны старта, вопроса и финала |
| `style.css` | внешний вид: цвета, кнопки, таймер |
| `script.js` | логика: таймер, подсчёт очков, переходы |
| `questions.js` | сами вопросы — меняются в одном месте |

Сделано на курсе «Вайбкодинг для подростков» вместе с AI-агентом OpenCode.
